Create and inspect a PersistentDisk

cats disk create project-data --size 20GiB --durability strict
cats disk ls
cats disk get disk_…

The create body explicitly carries durability, name, and size_bytes. The browser console uses the closed Strict default. Both browser and CLI persist the exact request and Idempotency-Key before transport, so an ambiguous response is recovered by exact replay rather than a second create.

Disk item lookup requires the immutable disk_… ID returned by create or list. Names are not accepted on item paths.

Disk snapshots

cats disk snapshot create project-data before-upgrade
cats disk snapshot list
cats disk snapshot show before-upgrade
cats disk snapshot restore before-upgrade
cats disk snapshot destroy before-upgrade

A DiskSnapshot is a remote restore point for one PersistentDisk, not a VM-memory snapshot. Create and restore require the disk to be remotely durable and unowned; if it is attached, its Cat must be stable Cold. Restore publishes the captured data as a new, higher disk generation rather than moving generation backward. It replaces the disk's current contents and does not clone a new disk.

The Snapshot row is also a garbage-collection root. Deleting it removes that protection; shared objects remain live while the current disk or another Snapshot still references them. Snapshot slugs may be reused only after delete, while immutable snapshot_… IDs are never reused.

Capacity remains immutable. The provider-neutral storage engine and Volume Authority still enforce RWO, fencing, durable roots, and stale-writer rejection; a product client cannot self-acquire or revoke a writer epoch.

Durability

The Guest sees a standard virtio block device. Strict durability means a successful FLUSH/FUA is remotely durable and survives permanent Host loss. Relaxed durability may acknowledge a local commit while the remote root trails; that local tail is unique data and cannot be discarded as cache.

A stale attachment epoch cannot publish a new root. Lifecycle coordination and takeover require the typed external authority path; a product client cannot self-acquire or revoke an epoch.
